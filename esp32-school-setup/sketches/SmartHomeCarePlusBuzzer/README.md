# SmartHomeCarePlusBuzzer — 2핀 부저 추가 버전

기존 PLUS 프로젝트와 분리된 확장 예제입니다. 원본 코드는 변경하지 않았습니다.

## 동작

1. PIR(GPIO25)와 IR(GPIO26)이 동시에 활성화되면 즉시 교육용 주의 경보가 발생합니다.
2. **GPIO23 부저 제어 신호가 켜지고**, 노란색 LED가 점멸합니다.
3. 이후 두 센서 중 하나 또는 둘 다 꺼져도 **부저는 계속 울립니다**.
4. 스마트폰의 `주의 알림 확인` 버튼(`POST /api/ack`)을 누르면 부저가 꺼집니다.
5. 버튼을 누른 당시 두 센서가 계속 활성화 중이라면 같은 동시 감지 구간에서는 재경보하지 않습니다. 두 센서가 한 번 해제되었다가 다시 동시에 활성화되면 경보가 재발생합니다.
6. `횟수·기록 초기화` 버튼은 부저를 끄지 않습니다.

**주의:** 두 센서 동시 감지는 위험/낙상/울음 판정이 아닙니다. 실험용 경보 조건입니다.

## 2핀 부저 연결

**부저의 정격 전압·소비전류·액티브/패시브 여부를 확인하기 전에는 GPIO에 직접 연결하지 마세요.**

코드는 **GPIO23 → 1kΩ 저항 → NPN 트랜지스터의 베이스**로 구동하는 일반적인 로우사이드 스위치 회로를 가정합니다.

- ESP32 GPIO23 → 1kΩ 저항 → NPN 트랜지스터 베이스(B)
- 트랜지스터 이미터(E) → ESP32 GND
- 트랜지스터 컬렉터(C) → 부저 마이너스(-)
- 부저 플러스(+) → 부저 정격에 맞는 전원(예: 3.3V 정격이면 3.3V)
- 부저 전원 GND와 ESP32 GND 공통 연결
- **자기식/코일형 부저는 적절한 역전압 보호 다이오드 등 보호가 필요할 수 있습니다.**
- 실제 트랜지스터의 베이스/컬렉터/이미터 핀 배열은 부품마다 다릅니다. 데이터시트 확인 전 연결 금지.

전원 공급 능력과 트랜지스터 정격은 부저의 소비전류를 기준으로 선정해야 합니다. LED/센서용 GPIO18,19,25,26 배선은 그대로 유지합니다.

## 부저 종류에 따른 코드 설정

`SmartHomeCarePlusBuzzer.ino` 상단:

```cpp
constexpr bool BUZZER_ACTIVE = true;
constexpr uint32_t BUZZER_TONE_HZ = 2000;
```

- **액티브 부저**: `BUZZER_ACTIVE = true`. GPIO23의 HIGH/LOW로 부저를 구동합니다.
- **패시브 부저**: `BUZZER_ACTIVE = false`. ESP32 Arduino Core 3.3.12의 LEDC PWM을 사용해 2kHz 신호를 생성합니다.

**부저가 2핀이라는 사실만으로 액티브형인지 패시브형인지 판단할 수 없습니다.** 부품 뒷면/측면 정격 표시나 구매 페이지 확인이 필요합니다.

## 접속 방법

- Wi-Fi SSID: `HomeCare-ESP32`
- 기본 시연 비밀번호: `homecare2026`
- PC나 스마트폰에서 해당 Wi-Fi에 연결한 후 `http://192.168.4.1` 접속
- 웹에서 `주의 알림 확인` 클릭하면 부저 정지
- 기본 비밀번호는 공개 저장소에 있으므로 실제 사용 시 반드시 변경하세요.

## 컴파일

Arduino IDE: **ESP32 Dev Module** / Espressif Core **3.3.12** 선택. 그다음 `SmartHomeCarePlusBuzzer.ino` 열고 업로드.

`check-build.cmd`는 원본·PLUS·부저 버전을 모두 컴파일하도록 갱신되었습니다.

**검증 범위:** GitHub 코드 업로드는 확인했으나 학교 PC에서의 실제 컴파일, GPIO 출력 및 부저 동작은 아직 검증되지 않았습니다. 부저 정격을 확인한 뒤 전원을 연결하세요.
