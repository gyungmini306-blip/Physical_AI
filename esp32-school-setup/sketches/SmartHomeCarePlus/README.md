# SmartHomeCarePlus — Wi-Fi 스마트 홈 케어 대시보드

기존 PIR/IR/LED 하드웨어를 변경하지 않고 ESP32 Wi-Fi AP와 로컬 웹 대시보드를 추가한 교육용 확장 예제입니다. 원본 `SmartHomeCare.ino`는 그대로 유지합니다.

## 무엇이 달라지나요?

| 기능 | 원본 | PLUS |
|---|---|---|
| PIR(GPIO25), IR(GPIO26) 감지 | 가능 | 가능 |
| 녹색/노란색 LED | 켜기/끄기 | 켜기/끄기 + 주의 시 노란 LED 점멸 |
| 스마트폰에서 센서 보기 | 없음 | ESP32 자체 Wi-Fi 웹 페이지 |
| PIR/IR 감지 시작 횟수 | 없음 | 가동 이후 누적 |
| 최근 기록 | 없음 | 마지막 12개 이벤트 |
| 두 센서 동시 감지 | 없음 | 2초 지속 시 주의 표시 |
| 알림 확인/기록 초기화 | 없음 | 웹 버튼 제공 |

**동시 감지 경고는 수업 시연을 위한 임의 규칙입니다.** PIR·IR 두 센서만으로 낙상·울음·위험 행동을 판단할 수 없습니다. 실제 돌봄·응급 알림으로 사용하지 마세요.

## 사용법

1. 기존 `setup.cmd`로 Arduino 개발환경을 설치합니다.
2. Arduino IDE에서 `SmartHomeCarePlus.ino`를 열고 **ESP32 Dev Module** 및 USB COM 포트를 선택합니다.
3. 코드를 ESP32에 업로드한 후 시리얼 모니터를 **115200**으로 엽니다.
4. 스마트폰 Wi-Fi 설정에서 **HomeCare-ESP32** 네트워크에 연결합니다.
5. 기본 시연 비밀번호 **homecare2026**를 입력합니다.
6. 스마트폰 브라우저에서 **http://192.168.4.1** 을 엽니다.
7. PIR 및 IR 센서에 반응시키면 1초 간격으로 화면이 갱신됩니다.

인터넷 접속이 없는 Wi-Fi 네트워크이므로 휴대폰에 '인터넷 연결 없음'이라고 표시되는 것은 정상일 수 있습니다. 접속 유지 여부를 확인하세요. 접속 IP는 시리얼 모니터에 표시됩니다.

**보안:** 기본 비밀번호는 공개 GitHub 저장소에 노출되므로 교실 시연용입니다. 실제 환경에서는 `AP_PASSWORD`를 변경하고, 타인 접근을 허용하지 마세요. 연결된 사용자는 인증 없이 이벤트 확인·알림 확인·기록 초기화가 가능합니다.

## LED 및 주의 동작

- PIR 활성화: **녹색 LED 켜짐**
- IR 활성화: **노란색 LED 켜짐**
- PIR+IR 둘 다 2초 이상 활성화: 웹 화면에 **주의 필요**, 노란색 LED **250ms 간격 점멸**
- 웹에서 '주의 알림 확인' 누름: 점멸 정지. IR이 계속 활성화되어 있으면 노란 LED는 켜진 채로 유지됨
- 두 센서 중 하나라도 비활성화: 주의 상태 해제
- 웹에서 '횟수·기록 초기화': 누적 감지 횟수 및 최근 기록만 초기화; 센서 감지는 중단되지 않음

PIR HC-SR501은 센서 자체적으로 HIGH 유지시간이 있으므로 사람의 움직임과 센서 출력이 1:1로 일치하지 않습니다. 센서 설정에 따라 감지 횟수도 달라집니다. 전원이 꺼지면 기록이 사라집니다.

## 소스코드 변경 지점

- `AP_SSID`, `AP_PASSWORD`: 스마트폰 접속용 Wi-Fi
- `BOTH_ALERT_MS`: 동시 감지 주의까지 필요한 시간(기본 2000ms)
- `PIR_ACTIVE`, `IR_ACTIVE`: 센서 출력 극성
- `PIR_PIN`, `IR_PIN`, `GREEN_LED`, `YELLOW_LED`: 기존 연결 핀

ESP32 GPIO에 5V를 직접 인가하지 말고, LED에는 전류 제한 저항을 사용하세요.

## 테스트 현황

코드의 일반 C++ 문법은 모의 헤더를 통한 정적 구문 검사에서 통과했습니다. **Espressif Core 3.3.12를 이용한 실제 컴파일과 ESP32 실물 동작은 아직 검증되지 않았습니다.** 개발 환경에서 `check-build.cmd`를 실행하면 원본과 PLUS를 모두 컴파일할 수 있습니다. 학교 PC에서 Wi-Fi 사용 가능 여부는 학교 정책에 따라 다를 수 있습니다.
