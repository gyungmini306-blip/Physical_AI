# Physical_AI

ESP32 기반 Physical AI 수업 과제 저장소입니다. 공통 개발 환경은 한 번 설치하고 과제별 코드는 별도로 관리합니다.

| 폴더 | 역할 | 상태 |
|---|---|---|
| [00_아두이노설치](00_아두이노설치/) | Windows Arduino, DHT, Python, MariaDB 공통 환경 설치 (Docker 불필요) | 기존 설치기 분리; Windows 재검증 필요 |
| [01_스마트홈케어](01_스마트홈케어/) | PIR/IR, LED, Wi-Fi, 부저, USB/BLE 실습 | 기존 코드 보존 |
| [02_온도변화알림](02_온도변화알림/) | 온도 상승·하강 알림 및 MariaDB 기록 (SQLite 보존) | 코드 구현 완료; 통합 검증 필요 |

## 사용 순서

1. 저장소를 ZIP으로 다운로드하거나 clone합니다.
2. `00_아두이노설치/setup.cmd`를 실행합니다. 설치된 PC에서는 반복 설치할 필요가 없습니다.
3. 해당 과제의 README를 읽고 Arduino IDE에서 원하는 스케치를 엽니다.
4. ESP32 Dev Module과 실제 COM 포트를 선택해 업로드합니다.

학교 PC 초기화 또는 드라이버 권한 제한 시 재설치/관리자 승인이 필요할 수 있습니다. 센서 실습은 안전 인증 제품이 아닙니다.
