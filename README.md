# Physical_AI

ESP32 수업 과제별 독립 실행 구성 (Windows 10/11 x64).

| 과제 | 실행 파일 | 기능 |
|---|---|---|
| [01_스마트홈케어](01_스마트홈케어/) | run.cmd | 개발환경 검사/설치, Arduino 예제 선택, USB/BLE 화면 |
| [02_온도변화알림](02_온도변화알림/) | start-server.cmd | 개발환경 검사/설치, Windows MariaDB, COM 감지, USB 수신, 웹 화면 |

각 폴더만 복사해도 실행할 수 있도록 설치 스크립트를 각각 포함합니다. 설치된 도구는 %LOCALAPPDATA%/ESP32SchoolKit에서 재사용합니다. 00번 공통 설치 폴더와 중복 관리 CMD는 삭제했습니다. 02번은 Docker/WSL 불필요. 01번의 과거 Dockerfile은 선택 참고용이며 실행 의존성은 아닙니다.

Arduino 스케치 업로드는 실제 보드와 배선을 확인한 뒤 IDE에서 수동으로 진행합니다. 웹/USB 화면 실행 전 시리얼 모니터를 닫습니다. 학교 정책, 인터넷, UAC 승인 여부에 따라 설치가 제한될 수 있습니다. 실제 Windows 원클릭 실행과 센서 동작은 별도 확인이 필요합니다.
